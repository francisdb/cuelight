# Test fonts

`cuelight_test_sans.ttf` is a subset of Noto Sans Regular (basic Latin,
U+0020 to U+007E, no layout tables, no hinting), renamed because "Noto" is
a trademark. It is a Modified Version under the SIL Open Font License 1.1;
the license, with the original copyright, is in [OFL.txt](OFL.txt).

Source: <https://github.com/notofonts/latin-greek-cyrillic>

Metrics the tests rely on: 1000 units per em, ascent 1069, descent -293,
no line gap; advances A 639, 1 572, space 260, comma and period 268.
